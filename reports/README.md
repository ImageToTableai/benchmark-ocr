# Reports

Markdown reports written after a run has produced its result files
(`manifest.json`, `metrics.csv`, `*_predictions.jsonl`).

Before publishing a public report, use:

- [receipt_v1_official_protocol.md](receipt_v1_official_protocol.md) — the
  frozen run contract for Receipt v1.
- [benchmark_release_checklist.md](benchmark_release_checklist.md) — the
  pre-publication validation checklist.
- [methodology_template.md](methodology_template.md) — the standard methodology
  section template.
- [artifact_quality_audit_2026-08-12.md](artifact_quality_audit_2026-08-12.md) —
  the data-integrity audit over the released artifacts.
